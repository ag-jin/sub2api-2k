## A. 账号管理
| # | 功能 | 我们现状 |
|---|---|---|
| M1 | 扫码纳管（扫码授权→自动每日签到→写凭证→重载） | ✅ 已对齐（admin.codebuddy.qr + 签到排程） |

| M5 | 积分余额实时查询（直连腾讯防滞后；实时/缓存Ns标注；批量刷新） | ✅ 已对齐（upstream_balance + CachedAgeSeconds） |

| M9 | 任务记录页（签到记录/原始日志/收益集中页；30s刷新；时间筛选；200条上限提示） | ✗ 缺 |
| M10 | 自动任务收益明细（旅行+100/领养+300；幂等语义显示；英文日志翻中文；45s采集落库+立即采集） | ✗ 缺 |
